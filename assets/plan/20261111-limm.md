# LIMM 论文复现

论文：Tang et al., *A learning-based interacting multiple model filter for trajectory
prediction of small multirotor drones considering differential sequences*,
Transportation Research Part C 174 (2025) 105115, DOI 10.1016/j.trc.2025.105115。

## 分批实施

1. 记录论文算法、实现假设及数据限制，收录用户提供的论文。
2. 独立 Python 包：差分序列、时间划分、归一化、Transformer-LSTM 与 LSTM 基线。
3. 可微分 LIMM：完整交互、学习状态/Q/R、逐预测步转移概率与稳定滤波。
4. 两阶段训练、保存/恢复、评估、仿真 CSV 与在线 ROS 适配。
5. 数值和梯度测试、可重复的小规模训练实验、结果报告与使用说明。

## 论文到实现

- §3.1/3.2：位置历史 40 点，未来 20 点，dt=1 s；速度历史 39 点、加速度历史 38 点。
- Eq.(1)：分别预测 P/V/A；V 累积积分、A 二阶离散积分，均返回未来位置。
- Fig.3/§5.1：3 层编码器 + 3 层解码器，解码输入为历史末 20 点 + 20 个零占位；输出接 LSTM；整个预测区间 MSE。
- Eq.(2)-(10)：保留完整 IMM 交互、滤波、似然归一化和状态/协方差组合。
- Eq.(11)-(12)/Fig.4：2 层历史 LSTM 编码，3 个模式各自的 fx/fQ/fR LSTMCell；共享历史编码的末端 h/c 初始化。
- §4.2(c)：可学习 logits [20,3,3] 沿目标模式 softmax；跨样本共享，但随预测步变化，不额外引入条件化转移网络。
- Eq.(13)-(15)：训练集 MaxAbs + 1.5 IQR；输入超出范围才按样本重缩放。所有尺度由历史/训练数据决定。
- §5.1：按时间先划分 7:1:2，再生成窗口；AdamW，lr=.001，weight_decay=.001，batch=128，每6000步乘 .9。

## 明确的实现选择和限制

论文没有完整开源代码、网络宽度/头数/激活/训练轮数/初始协方差/协方差参数化。
实现采用可配置隐藏宽度64、4头、FFN256、dropout .1；Q/R 使用 Cholesky 因子保证正定；
Joseph 协方差更新和 log-likelihood softmax 改善稳定性。所有选择必须在包 README 中公开。
Fig.4 的共享状态必须有共同物理意义，本实现统一在速度空间融合三路转换后的预测，
最终积分回位置；符合 §5.3 所述的未来速度预测。位置以每条完整飞行的起点平移到局部坐标。

当前仓库只有仿真数据，没有论文 MavicAir2/Payload 等17组原始数据及作者权重。
合成数据实验只能证明训练、推理、接口及数值性质可运行，不可声称复现论文表2/3性能。
Transformer/LSTM 基础算子使用 PyTorch 官方实现；模型封装在独立可安装目录，方便以后拆仓库，
不创建未经用户指定的远端仓库，也不引入不明许可证的第三方模型代码。
