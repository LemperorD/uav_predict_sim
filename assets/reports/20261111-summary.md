# 20261111 任务完成记录

## 实现

1. 基于统一 `Predictor` / `DiagnosticsProvider` 实现六状态 Pose-KF，接入工厂、ROS 参数、CMake；增加只用位置观测的 KF 基线。当前默认算法为 `pose_kf`，可切换 `imm` / `kf`。
2. 提取 `PredictorVisualization` 曲线基类。IMM 显示概率，Pose-KF/KF 显示速度误差，公共误差/协方差面板和三维场景共用；可用显示配置覆盖 profile 和纵轴范围。
3. CSV 追加真值/观测/估计速度和观测姿态；matplotlib-cpp 按列名读取，可配置多个基线 CSV，叠加曲线并导出 `comparison_metrics.json`。支持禁用离线绘图和仅重新生成结果。

论文第 VI-A 节式 (19)–(24) 的 Gamma/Q 维度和增益打印存在不完整之处。本实现采用对角 Gamma、创新协方差求解和 Joseph 校正，并将重力/推力方向转换为 ROS ENU。实现约定及参数详见 `src/predictor/README.md`，不宣称严格复现论文实验。

- `predictor`、`prediction_visualize` 编译安装成功，使用现有 CMake 构建目录；未重建全部 EGO 规划器包。

- prediction_visualize 的 4 项 CTest 全通过，覆盖曲线指标映射、真实 matplotlib-cpp 基线叠加、重排/旧 CSV、缺失文件与字段拒绝，以及原模型姿态/主题测试。
- Python 语法检查、修改文件 clang-format 检查与 `git diff --check` 通过。全项目 `scripts/format_cpp.py --check` 仍被 EGO 第三方目录的原有格式差异阻断，未修改这些无关文件。
