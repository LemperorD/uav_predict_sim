## 参数化轨迹

新增 `src/predictor/include/predictor/trajectory.hpp`，集中定义七种轨迹及解析位置、速度、加速度：

| trajectory | 运动 | 主要参数（均带 trajectory_ 前缀） |
| --- | --- | --- |
| hover | 悬停 | origin |
| straight | 匀速直线 | origin、velocity |
| acceleration | 恒加速度 | origin、velocity、acceleration |
| circle | 水平圆周 | origin、radius、angular_speed、circle_phase |
| helix | 匀速升降螺旋 | 圆周参数、vertical_speed |
| figure8 | 三维八字 | origin、amplitude、frequency、phase；y 频率为 x 的两倍 |
| sinusoid | 三轴独立正弦 | origin、amplitude、frequency、phase |

默认三维八字、旧匀速/恒加速度参数默认值保持兼容。启动文件按轨迹 t=0（包含相位或 CSV 首行）初始化仿真器，消除非默认起点在首条指令前的错误跳线。`input_csv` 非空时覆盖轨迹名称，仍按原格式插值回放。参数在启动时检查向量长度、有限数值、名称与正半径。

配置入口：`src/predictor/config/simulation.yaml`。详细公式、单位、有效参数及螺旋 YAML 示例见 `src/predictor/README.md` 的“轨迹选择与调参”。只需修改 YAML 的 `trajectory` 及对应参数，并选择新的 `output_dir`，即可通过原有运行入口跟踪和预测：

```bash
scripts/run_simulation.sh --headless
# 或自定义配置；需要 Pangolin 窗口时去掉 --headless
scripts/run_simulation.sh --config /absolute/path/to/config.yaml --headless
```
