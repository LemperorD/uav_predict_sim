# 模型、控制与实验验证

## 检查范围和阈值

`ctest --test-dir build --output-on-failure` 运行以下检查。核心验证全程不需要 ROS、Python 绘图库或显示器；`records_and_replay` 使用可选 Python 解释器和标准库，开启绘图时还实际生成 PNG。

| 检查 | 独立依据 | 当前阈值 |
| --- | --- | --- |
| `physics`：悬停 | 0.98 kg 模型，等转速产生 mg，5 s 固定步长积分 | 位置、速度及角速度漂移 < 1e-10 |
| `physics`：分配 | 各轴正 0.01 N·m，验证实际 wrench 和角速度方向 | wrench 残差 < 1e-12，角速度同号 |
| `physics`：电机 | 转速阶跃与一阶响应解析指数比较 | 0.1 s 后 RPM 向量误差 < 1e-5 |
| `physics`：自由落体 | 关闭最小转速，1 s 自由落体解析式 | 位置误差 < 1e-10 m |
| `physics`：旋转 | SO(3) 正交性、行列式及 2/1/0.5 ms 步长比较 | 群误差 < 1e-12；细步长旋转差 < 1e-11 |
| `flatness_control`：解析映射 | 对八字参考的 R 做独立中央差分 | Rdot < 1e-8，Rddot < 2e-6，alpha < 1e-8 |
| `flatness_control`：力一致性 | m(a + ge3) 与 fRe3 | 残差 < 1e-12 N |
| `flatness_control`：跟踪 | 悬停、升降、螺旋、空间八字各 10 s，1 ms，保留电机滞后 | 跟踪 RMSE < 0.12 m、峰值 < 0.3 m、无转速饱和 |
| `upstream_regression` | 独立保存的上游控制器和动力学源文件 | 外环 force/R 差 < 1e-12；10 ms 状态差 < 1e-7 |
| `causal_experiment`：预测 | CV/CA 的解析三维轨迹 | 预测位置误差 < 1e-9 m |
| `causal_experiment`：因果性 | 仅改变 t > 2 s 的隐藏参考；位置偏移采用 C4 连续项 | t0 ≤ 2 s 的预测逐点完全相同，后续实际真值确实不同 |
| `causal_experiment`：反馈 | 初始位置偏移 (0.1, -0.08, 0.06) m | 4 s 后跟踪误差 < 0.01 m |
| `records_and_replay` | 从 CSV 独立重算推力轴动力学、ADE/FDE/RMSE；重读日志 | 力/加速度及指标误差 < 1e-10；复现日志完全相同 |

这些阈值检验数值和工程正确性，不是实机性能保证。标称测试从平坦参考状态及相应电机转速初始化，预测器观测含噪但控制器读取理想当前状态。

## 已测结果

本机 GCC 11.4 / Eigen 3.4.0 / yaml-cpp 0.7.0 / Boost 1.74，Release 构建：

- 10 s 悬停：位置跟踪 RMSE 为 0。
- 10 s 升降：RMSE 约 0.000443 m，峰值约 0.000660 m。
- 10 s 螺旋：RMSE 约 1.36e-6 m，峰值约 2.19e-6 m。
- 10 s 空间八字：RMSE 约 0.000544 m，峰值约 0.00118 m。
- 上述标称场景均无电机分配饱和。
- 与上游同参数、同阻力设置的 10 ms 动力学对照：位置差约 8.97e-16 m，旋转矩阵差约 1.11e-16。

`configs/eight.yaml` 的 16 s 实验：

| 项目 | 结果 |
| --- | --- |
| 位置跟踪 RMSE | 约 0.000597 m |
| 位置跟踪峰值 | 约 0.001177 m |
| 完整预测数 | CV、CA 各 136 次 |
| 不完整尾部预测 | 各 20 次，保留但不聚合误差 |
| CV ADE / FDE | 约 0.93563 / 2.29983 m |
| CA ADE / FDE | 约 0.43684 / 1.30632 m |

预测误差相对较大是因为只从历史位置延拓，并不知道未来机动；它与控制器的参考跟踪误差不是同一个量。不能将较小跟踪误差当成预测准确率。

## 上游对照的适用范围

`tests/upstream/` 的原始回归副本只去除 ROS include、改为系统 Boost include，并加来源说明。测试运行前显式初始化外扰。

`control.upstream_compatible: true` 保留上游加速度误差项、零期望角速度阻尼及 Psi ≥ 1 时的推力门控，用于正常正飞、非奇异参考的公式对照。它不实现外部 yaw 覆写、标定 corrections 或上游有歧义的倾角限幅分支，因此不是整个 ROS 节点的逐位复现。正式实验默认 `false`，使用一致的姿态导数前馈。

## 独立性与显示验收

独立验证只复制 `CMakeLists.txt`、`LICENSE`、`include/`、`src/`、`apps/`、`tests/`、`configs/`、`third_party/` 到临时空目录，开启绘图、Pangolin 和测试后从零构建。副本不存在 `last/`、`ego-planner/` 或原仓库 `.git`，不使用原构建缓存。2026-11-02 已实际完成该独立构建，5/5 项检查通过，包含生成 PNG 和重读日志。

四份 PNG 已实际生成并逐一检查布局、坐标、三维曲线及图例；修复了旧 matplotlib-cpp 的 3D axes API 和借用 NumPy 缓冲区的生命周期问题。PNG 测试检查文件头和有效文件大小，图形内容另经人工视觉检查。

Pangolin 已编译/链接，当前开发会话没有 DISPLAY 或虚拟显示器。待在桌面终端检查：鼠标视角、真实机体姿态、旋翼编号、跟随相机、暂停、10 ms 单步、时间滑块、速度切换和预测图层。没有把编译通过表述为窗口交互已验收。

约束优化预测器、连续时间约束证明、带噪状态反馈、任意扰动配置、翻转及接地接触模型尚未实现。
